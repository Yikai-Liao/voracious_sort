# Stable grouping and recycling proof

The digit mask covers every varying bit and has exactly one set bit. The first live digit determines the common bits, hence exactly the same low/high bucket IDs as ordinary byte scatter. Classification visits every live record once in source order; the extra probe is explicit. A chunk has at most usize::BITS records and is fully represented by one word, so the live mask never includes padding and no shift equals the word width.

In each chunk, selected offsets ascend separately for low and high. Chunks ascend within their input block, and logical input blocks ascend. Each bucket receives the same record subsequence as scalar scatter, including payload/identity order. Fixed byte-pass order and ordinary bucket fixup therefore preserve complete stable ordering.

Let i be the current logical input index and B the block size. There are i-R previous input blocks, each with at most B live records. After J payload copies, at most floor(J/B) output blocks can have filled. Before all B records in the current block have been copied, J is below (i-R+1)*B. A newly reserved physical block with logical index i is possible only after copying the final record of a full current input block; it is first written on the next record. A partial block creates additional slack. This bound counts records and does not require their offsets to ascend within the same input block. Every current live payload is read exactly once before its output store; source permutations contain distinct physical IDs. Thus grouping cannot overwrite an unread current or future input cell. No input staging allocation is needed.

Bucket refill still publishes usage and increments counts immediately when its local cursor reaches its end; final cursors/end pointers are published before ordinary fixup. Grouping may assign physical free blocks to buckets in a different chronological order, so compaction evacuation counts can differ. Direct tests validate the actual physical permutation invariants and stable oracle, and bound final compact copies by n + floor(n/B)*B. Final release work/heap evidence is required if the screen passes.
