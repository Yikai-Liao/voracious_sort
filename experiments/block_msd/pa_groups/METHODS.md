# Grouped binary writes

UnifiedGroups inherits every UnifiedPrepared policy flag and the same fixed offline 16 MiB parameter. For a Block digit with exactly one varying bit and records no wider than a machine word, it uses one machine-word mask per chunk within the current logical input block. It evaluates labels in original order, then copies low records in increasing offset order followed by high records in increasing offset order. Chunks and logical input blocks remain in their original order. All other digits/records keep the original scatter loop. No independent sorter or outer key-width dispatcher is introduced.

The grouped helper has no const BYTE parameter and is inline(never). Its native-key bit mask is prepared once. The two bucket cursors are private to the pass and published before normal fixup. The original radix count, scratch allocation, perm/perm2/usage/counts and compact protocol remain. It adds a first-live-label probe per eligible pass, counted in actual label evaluations. Scalar field loads used for labels and later payload copies are separate; their cost must be measured.

The allocation order across buckets can change. Every bucket still sees exactly its original record subsequence, so the stable logical output of each pass is unchanged. Evacuation/compact copy counts can therefore differ and are measured explicitly rather than claimed equal.
