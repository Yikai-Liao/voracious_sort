# Pa 的终止路径与偏斜编号组合

本轮沿用 [第一轮独立改动](../pa_screen/METHODS.md)，该轮代码与原始结果冻结在
`333bce8`。原 Pa、冻结 LSD 和 Stable MSD 均保留。这里只扩展同一个节点函数的
classifier 选择，不按 key 类型调用不同排序器。

| 方法 | 节点策略 |
|---|---|
| Pa / Pa_ref | 原 Pa／同一新框架下复现原 Pa |
| Pa_terminal | 完整 key 已消费时使用 identity，分布后不扫描分组 |
| Pa_core3 | terminal ＋真实大子桶里的三路编号；保留原融合顺序扫描 |
| Pa_probe3 | core3 ＋根节点的固定 64 点信号；完整多数证据优先于完整 key 分布 |
| Pa_both3 | 首轮组合：terminal ＋独立顺序探测＋真实大子桶三路编号 |

## 根节点信号

仅在根节点、key cap 大于 8 时，读取等距的 64 个 key，包括首尾。
在样本中进行 Boyer–Moore 并记录升降序关系；当票数超过 32 且样本既非升序也非降序，
才在完整节点的必需准备扫描中融合候选计票。普通子节点仍只接受真实大子桶信号。

这不是多数验证，也不是排序终止依据。样本可能误导或漏检；误导会增加准备成本，
漏检则回到原 Pa。完整节点的最终票数必须超过节点长度一半，才启用三路 classifier。
票数本身是候选出现次数的充分下界，因此不需要第二次完整验证扫描。
所有 key 仍走完整扫描、稳定分布和精确终结。专项测试覆盖故意误导样本但全体无多数的输入。

根节点如果通过完整多数证据，即使普通 Pa 的字节预算足够消费完整 key，也先用
一字节的 `<pivot / =pivot / >pivot` 编号。等值组直接完成，两侧继续使用同一个节点函数；
两侧不保证新增公共二进制前缀，故保守保留有效 cap。Core3 保留首轮的 terminal 优先级，
作为没有根探测的对照。Probe3 因而同时测试“提前发现多数”和“在完整分布前利用多数”。

64 是本轮固定实验常数，未搜索样本数／阈值。样本扫描没有加入 `candidate_records`
（该列只计完整准备扫描），其最多 64 次 key 读取计入实际时间；不把该列写成全部探测量。
完整多数约 90% 的 deep_skew、完整 key 各异的 majority_prefix、稀疏位等频输入必须分别解读。
这轮并不证明对任意偏斜或所有重数都有效；中等多数可能未通过保守票数证据。

## 空间与测量契约

所有候选共用既有稳定 block / dense 分布后端和 128 条比较叶子。
分布工作区在递归之前释放；样本不分配堆存储，也不缓存每记录 label。
报告 requested heap peak，排除输入／恢复副本／oracle；它不含递归栈、allocator 保留量和 RSS。
固定 B 的目录是 O(n/B)，不声称严格 O(√n) 总辅助空间。

release 时间版和工作计数版分别冻结在 `target/pa-probe/time` 与 `work`。
计数由 feature 编译移除；堆统计另跑。时间包含 scratch 分配／释放、比较叶子与终结，
不含恢复与完整稳定 oracle 核对。每组恢复同一输入地址，调用顺序轮换并交替反转；
方法表两处放原 Pa，按固定 slot 计算 A/A。保留全部原始样本和失败候选。

`Pa_ref` 用于观察新框架本身成本。不同方法的代码布局／编译特化也可能影响耗时；
对没有工作量变化的小幅差距，不能仅凭中位数归因为策略收益。
