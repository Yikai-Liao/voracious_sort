# Pa 的多数前缀区间实验

本轮沿用 Pa 的节点访问、稳定块分发、比较排序叶子及工作区所有权，仅替换少数偏斜节点的分类器。`Pa_band` 允许在根节点和实际多数子节点取样；`Pa_band_child` 只允许后者，用于分离根节点探测的价值。两者均包含上一轮 `Pa_terminal` 的终止节点优化，保留原有融合的全量变异／有序扫描。`Pa_ref` 是共享协议中的原 Pa 对照。主库默认算法未改。

## 从完整键多数到前缀区间多数

原 `Pa_probe3` 只有在一个完整键获得严格多数证明时，才可把等值组立即终止。新分类器把“等于一个键”推广为“位于一个二进制前缀区间”：小于、位于、大于该区间分别标成 0、1、2。区间内的键可以全部不同；中间组仅消耗共同的高位，随后按剩余低位继续排序。

在允许取样的节点，先检查当前位宽上限是否大于普通 Pa 的字节预算。对 64 个均匀位置的键取数值中位数，以相对该键的 XOR 距离第 40 小值定义候选共同前缀；单调样本跳过。40/64 是首次筛测前固定的成本启发式，本轮没有按测量结果搜索阈值。样本还必须包含区间外的键，防止仅把全局已有共同前缀当作新收益。

候选只决定是否在原本必需的全量准备扫描内融合一次区间人口计数，不作为正确性证明。全量扫描后必须同时满足：

- 区间人口严格超过节点一半；
- 按实际有效位宽计算，跳过的前缀长于该节点普通 Pa 的粗分预算。

批准后，区间内保留低位宽度，左右两组保守保留节点实际有效位宽。左右组各小于父节点一半，因而无需假设它们另有共同前缀也能保证进展。中间组缩短位宽；剩余 0 位时等值终止。稳定块分发保持相同标签内的顺序，后续递归保持最终稳定性。区间标签及剩余位宽映射另有穷举测试。

取样固定栈数组，无新增堆分配。每个分发工作区在访问首个子节点前释放。采样和全量批准成本均在正式计时内。

## 区分输入的结构

- `deep_skew`：90% 完整键为零，少量键在不同位退出。保留作为旧案例，但它的收益不能单独证明共享前缀的收益。
- `majority_prefix`：90% 键共享上半段前缀，低半段随机，另 10% 全位宽随机。中间组需要继续排序。
- `deep_unique90/98`：先按 n 预留按字节向上取整的唯一编号低位；从最高字节向下，每层以 90% 或 98% 概率保留零，首次退出用非零字节，后续高字节随机。最后打乱。所有完整键互不相同，逐层存在退出质量；90/98 是逐层保留概率，不是相同完整键的比例。
- 1,048,576 条 128 位键预留 24 低位，剩余 13 高字节用于逐层偏斜；64 位剩余 5 字节，32 位仅 1 字节，可作为不够深的负对照。禁止在键容量不足时运行该生成器。
- `common_high` 是所有键已有共同高位，原 Pa 的变异扫描本来会去掉；它与需要分离少量区间外记录的多数前缀问题不同。

工作量 CSV 的 `band_nodes` 为批准的区间节点数，`band_records` 为这些节点内区间人口之和，`probe_records` 为新分类器取样键数。`candidate_records` 为融合候选判断的全量扫描记录数。旧 `Pa_probe3` 的 64 点采样不计入新增 `probe_records`，不要跨方法将该字段直接解释为全部探测成本。其他 `scatter_records`、`compact_records`、`label_evals` 和深度等沿用旧定义。

## 测量边界

时间 ELF 完全移除工作量计数；工作量及请求堆峰值分开运行。每次完整排序后与稳定 oracle 比较键、原始 id 和全部 payload；同一布局／案例复用实际输入地址。包含输入恢复后的排序、工作区分配及释放，排除生成、恢复及 oracle。各方法轮转并交替反向运行，Pa 在固定列表首尾重复用于 A/A。单 CPU 2，单线程；构建及测试完成后才开始计时。

KVM 宿主并非独占，细小差别按同案例 A/A 分布解释。报告分别展示 Block LSD 和当前 Stable MSD。后者是已有的递归缓冲实现，其堆占用不能当作所有稳定 MSD 的下界。请求堆峰值不包含栈、分配器保留或 RSS。

正确性探针的 32,769 条全异 128 位键／48B 记录显示 scatter 435,842 → 110,745，但 compact 64,513 → 66,933；减少 scatter 不保证所有搬运计数一起下降。最初将 compact 也应下降写成测试假设，失败后保留日志并改为独立记录 compact，算法没有因该失败改动。正式收益以完整排序时间判定。
