# Goal 第一轮：修复已测回退

原始 Pa、Pa_terminal、Pa_band 及 Frozen Block LSD、Stable MSD 都保留为独立对照。默认库入口不变，所有候选仍使用同一 Pa 节点机制与 Block/Dense 工作区预算，不按键宽路由到独立排序器。

本轮四项独立消融：

- `Pa_terminal_sortleaf` / `Pa_band_sortleaf`：只将 <=128 条叶子的插入排序替换成当前 Rust 工具链的稳定 `sort_by_key`；测量实际分配。
- `Pa_band_nested`：现有采样宽区间之外，对同一样本中位数试一个能够在下一节点普通字节预算内直接完成的内层区间。仅当它更窄时在已有完整扫描中增加成员计数；实际严格多数和有效前缀跳跃批准后优先使用，否则回到原区间。
- `Pa_ordered_tiled`：只替换独立顺序探测，用 128 条等值归约和按方向分块相邻关系证明，失败前不修改输入。
- `Pa_terminal_local` / `Pa_band_local`：同一分类标签最高活跃字节先分发，再在高位区间内完成低字节；所有记录原活跃字节仍各处理一次，区间使用既有 Dense/Block 预算。

`Pa_unified` 是组合筛测项，包含以上机制。单项不通过的机制不因组合结果偶然较快而获准。首屏后按正负证据裁剪，保留失败原始数据。

验证顺序：行为稳定 oracle/边界测试 → 冻结 time ELF → 独立小屏 → 仅有依据的候选做种子 42/7、B64/512、大小规模确认 → 独立 work/heap 和 ASan。计时阶段不得运行本轮编译或测试。

持续 Goal 仍未完成。验收包括普通输入、完整重复偏斜、完整键全异的渐进共享前缀偏斜、宽键有序/全等、B512 大记录；已发现的明显回退需要解决。报告每一项相对 Pa、当前候选、Stable MSD 的收益与剩余缺口，配对反向重复和 Pa A/A 约束结论。
