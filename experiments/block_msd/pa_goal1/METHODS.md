# Goal 第一轮实现

`Pa`、`Pa_terminal`、`Pa_band` 为本 ELF 内的旧算法控制。`Pa_ref` 仍可用于核对普通 Pa 的同结构控制。Frozen Block LSD 和修正过逆序稳定性的 Stable MSD 使用原快照源码；后者辅助空间更大，不能只比较速度而隐去内存。

四个机制及组合见 PLAN.md。所有计时包括工作区申请与释放，计时后核对完整 key、原始身份及所有 payload 字节。输入生成后恢复到同一实际分配；同一 rep 按旋转且相邻反向顺序执行。`Pa` 两个 slot 测 A/A。环境为共享 KVM 单 guest CPU2，不能假定独占宿主或固定频率。

## 内层前缀

原候选保留采样中位数并预存其前缀；内层使用同一中位数、相同 cap。最小严格多数 `m=n/2+1` 的普通预算为 `8*ceil(log256(m))`，等于 `8*ceil(bitlength(n/2)/8)`。仅当此 low 小于原区间 low 才构造。两个成员计数融合在必需的 variation 扫描，顺序证明按策略在扫描外专门化。批准仍要求实际严格多数且实际 width-low > 本节点 coarse。优先批准内层，否则保留原候选的判断。

内层中间组在下一节点预算内可以直接完成，包含互不相同的低位键。中间组降低位宽；两侧各小于父节点半数，保持递归进展。`terminal_band_nodes` 只记真正选中的内层区间，不把采样提议当成功。

## 稳定叶子

只更换原 <=128 条比较排序叶子。`sort_by_key` 按转换后的 native key 排序，保证符号和浮点键采用相同转换次序。它的分配/栈行为由当前工具链决定，实际 heap 用独立 memory 模式测量，不从名字推断为零开销。

## 顺序证明

每 128 条先归约与首键是否全等，只在失败块标量定位首异点。随后在循环外选择升/降方向，在偏移相邻切片上按块归约。已验证等值前缀和首个严格关系之后的所有相邻对都覆盖，包括 tile 边界和余数。失败前不写入；全等/升序返回，降序仅在完整通过后反转并恢复等值组身份。

`order_records` 记显式 key 提取调用，偏移相邻切片一对计两次。它与 prepare/candidate 目的计数可能重叠，不能简单相加为总扫描次数。

## 局部完成同一标签

改变同一次 classifier 分发的物理执行：只有多活跃字节且整段超过 Dense 预算才先完成最高活跃字节。根 Sorter compact 并释放后，逐个高位区间用现存 Dense 或 Block 路径完成低字节。活跃 byte 的全局 variation 保留，singleton 也计原有低字节分发，因此每记录原活跃字节恰好各一次；分类结果、Pa 子区间和理论 scatter 工作不变。新增边界扫描、局部 histogram、额外 compact 是实测成本。

`passes` 统计实际物理 pass，局部执行可能由3增加到513；`scatter_records` 才是按记录加权的分发量。返回的路径 pass 数仍为原活跃字节数。

64位 release 下根 Block 请求 heap 为 `K + 9*(floor(n/B)+512) + 12288`，其中 `K=512*B*sizeof(T)`；Dense 实际 heap 为 `m*sizeof(T)+levels*256*8`，准入额外保守计两组 stack cursor，因此 <=K-4096。局部 Block 的目录随子区间缩小。作用域保证两份 workspace 不并存，所以单次局部分发的 requested heap 不超过原根分发。此结论不等于整个候选的 RSS 或栈峰值相同，稳定库叶子需要另测。
