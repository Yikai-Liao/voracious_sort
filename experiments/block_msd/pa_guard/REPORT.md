# Pa：采样成本门与缩桶首屏

**Goal 未通过。** 64点成本拒绝改善了大记录多数前缀的新增成本；缩桶没有修复u16稀疏差距，并在u128偏斜输入上出现新增回退。组合方法仍是实验候选，不能作为最终交付或替换主库默认入口。

本阶段固定源码 `a435c728117675abc515463f784d74e14743d7a3`，156项源码/Cargo文件和time ELF由清单固定。三份CSV共640行，均为seed42、每项4次：窄键256行、大记录96行、中等规模288行。每项先warmup，再旋转/相邻反向执行；Pa双slot提供逐场景A/A。每次恢复同一输入分配，warmup及正式排序均核对完整稳定oracle。

## 独立机制的收益与回退

下表为墙钟中位数，单位ms。cache为上一阶段选出的16MiB门槛；sample只加64点成本拒绝，radix只加变化范围缩桶，组合同时启用两项，其他统一节点机制相同。方法及空间边界见[METHODS](METHODS.md)。

配对比先计算同seed/rep的方法/对照，再取中位数，不能用表中两列中位数相除替代。sample在大记录多数前缀上相对cache为0.912，p10/p90为0.890/0.932；全异逐层90%为0.917，0.852/0.939。对应Pa A/A分别为0.937/1.054和0.936/1.012。这个首屏支持保留采样成本门继续研究，但还不足以证明全面消除回退。大记录均匀随机sample/cache为1.041，0.979/1.090，Pa A/A为0.969/1.007；正对照的新增成本仍需正式保护检查。

缩桶的负例更明确：u128多数前缀radix/cache为1.249，p10/p90为1.239/1.260；组合/cache为1.194，1.101/1.348，而Pa A/A为0.983/1.029。u128全异逐层90%的组合/cache为1.216，1.127/1.300；wide32同场景为1.105，1.092/1.320，对应Pa A/A分别为0.989/1.125和0.979/1.115。不能以这些方法仍快于Stable MSD抵消相对cache新增的成本。

窄键保护也没有通过：u16稀疏radix/Stable配对比为1.133，p10/p90为0.970/1.144，radix/cache为0.999；该cell Pa A/A为1.035/1.097。它没有证明修复已知差距。u8稀疏组合/Stable为1.153，1.090/1.164；组合/cache为1.107，1.058/1.147，Pa A/A为0.891/1.064，仍有新增回退信号。身份记录及全部首屏cell保留在[窄键](summary-screen-narrow-b64-s42.csv)、[大记录](summary-screen-large-b512-s42.csv)、[中等规模](summary-screen-medium-b64-s42.csv)摘要中。

在这些B64布局上，固定门槛不启用局部完成，sample的时间差不能直接解释成采样机制收益。缩桶仍可作用于Block路径。共享环境、方法生成代码及执行次序也会影响比较；本阶段只使用同一冻结ELF内的配对，不把上一阶段另一ELF的cache中位数与本阶段直接相减归因。

## 验证与剩余范围

25项debug针对性测试通过，运行84.16秒；runner的1项工作负载测试及全部目标/feature编译检查通过。最初debug构建因磁盘满失败，日志保留为`debug-disk-full.log`，没有运行到排序断言，不能记为排序错误。三份测量全部成功、stderr为空；[最终核验](validation/evidence-final.log)检查640行的完整性、slot/rep、输入地址及冻结源码/ELF hash。[独立复算](validation/report-check.log)核对全部摘要和A/A统计。

**本阶段未完成ASan、release工作量及requested-heap实测。** runner测试名中的workload不等于独立work计数实验。缩桶后的根scratch可能变小，但后代Dense仍可能超过该根值；只能保留原256桶预算包络的设计约束，不能由此宣称组合峰值不变。更早Band的验证不覆盖本阶段新增机制。

正式12次矩阵、完整偏斜/B512保护和新seed20261018均未执行，详见[固定验收范围](ACCEPTANCE.md)；现有`final.sh`和`heldout.sh`是后续计划，不是本轮完成记录。共享KVM Xeon Gold6140、单worker固定guest CPU2，不能保证宿主独占或频率固定。全部离群值保留，逐文件`noise-*.csv`给出各cell的A/A和wall/thread-CPU；p10/p90是样本分位数，不是置信区间。[复现说明](REPRODUCE.md)、[环境](environment.json)、[原始数据](measurements/)和`evidence-sha256.txt`共同固定这次首屏的证据边界。
