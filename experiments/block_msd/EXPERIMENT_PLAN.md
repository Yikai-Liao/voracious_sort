# Block MSD 实验安排

Latest follow-up: the [749ca4d work-reduction plan](work_reduction/PLAN.md)
has been implemented and measured in the [work-reduction report](work_reduction/REPORT.md).
The earlier proposals and stopping criteria below remain historical context.

目标是在稳定性与受限额外空间成立的前提下，分别量出扫描、块管理、归位时机和记录搬运的代价。每项实验保留独立对照；研究分支中的候选不自动成为默认实现。

稳定分桶构造的前人出处见 [COUNT_FIRST.md](COUNT_FIRST.md#prior-art)。当前工作研究这些机制的实现取舍，不把共享边界与整块置换当成新发明。

## 执行顺序与唯一改变量

| 顺序 | 实验 | 固定部分 | 唯一改变量与主要问题 | 当前状态 |
| --- | --- | --- | --- | --- |
| 1 | 大节点归位＋连续稳定 MSD | 现有 free-list、边界共享与 scatter；完整变化位扫描 | 本层先结束块管理，小节点退出全局 Writer，是否抵得过提前归位 | 已完成第一阶段，收益与偏斜反例均保留 |
| 2 | 单调前缀写回 | 同一节点归位策略、缓存准入、直方图、叶子排序 | 完整块按完成顺序写回已读前缀，替换物理 free-list/链；增加的写回能否换来管理简化 | 已实现并通过验证；与 free-list 独立比较 |
| 3 | 边界 ID 顺序携带 | 冻结的 free-list setup 与相同 scatter | 删边界 Vec 和二分查找，保持分配序列及物理 ID 完全相同 | 已完成真实 Arena 等价性验证与完整排序检查 |
| 4 | 固定 128 条叶子合批 | 归档全局 Stream/Writer、每个叶子的原输入与排序调用 | 一次 gather 多个叶子、分别排序原子切片、一次写出；不扩大比较问题 | 已实现；不与 v5 terminal_fusion 混用 |
| 5 | 归位准入预算 | 冻结第 1 项的 free-list 归位 backend | 先验证 `m <= K*R`，再单独研究势函数；是否避免长链反复收费 | 已实现 R4 与整数势函数两个独立变体 |
| 6 | 单层少数桶暂存 | 冻结全局 Stream 后端用于回退；只特化预算允许的节点 | 暂存少数桶及位置，大桶按右移前段/不动中段/左移后段整理一次 | 已实现；作为延迟链的独立控制组 |
| 7 | 整段偏斜链延迟物化 | 第 6 项的整理原语、相同总预算及普通回退 | 大桶保留原位、跳过空位继续统计，在一段链结束时只整理一次 | 已实现有界 holes 视图、完整预算与整段 flush |
| 8 | 子桶直方图预统计 | 归档全局 Stream 分桶 backend，实际仍按一位 scatter | 用固定总预算保留联合计数，衡量省下的读取与随机表更新代价 | 已实现；统一比较预算 0 和 512 KiB |

顺序 5 的线性 R 规则与势函数规则分为两个变体。顺序 6、7 分开，不把“每层少搬一次”和“整段链只整理一次”混成一个收益。边界携带验证可以提前准备，但其代码不进入尚在计时的第 2 项。

## 各项必须先验证的条件

### 单调前缀写回

- 当前记录先完整复制到 scratch，才允许触发完整块写回。
- 每次写回检查 `(F+1)*b <= k`，其中 k 包含当前已复制记录。
- 不完整逻辑尾块只在输入全部读完后写出；完整块归位不碰物理短尾。
- 同桶记录的逻辑位置仍按输入次序分配；与 free-list 版本比较完整身份、分桶树及缓存准入计数。
- scratch、目录、共享边界计数均入账；新增的 scratch→数组写回单独计数，不宣称必然少复制。

### 边界携带与叶子合批

- 边界：空桶不清 carry；同一物理块内的头尾共享；整块结束清 carry。对旧 setup 逐桶比较 prefix/suffix ID、游标范围、full/suffix pending 及 free-list 最终状态。
- 先覆盖小计数穷举、空桶链、跨块桶、短尾及不同 b，再运行完整 Rust 排序。分配 ID 不一致即停止，不用“排序结果一样”代替等价性。
- 合批：批次总长度最多 128，只包含已经终结的相邻叶子；每个叶子的排序输入、边界和排序调用数量不变。
- 记录字节搬运应仍为 gather＋写出；另外统计 Stream/Writer 高层调用数和实际连续区间数。不给合批计入尚未减少的 scatter/归位收益。

### 归位预算

- 直方图之后、scatter 之前做决策。拒绝时，当前整个连续切片交回冻结的低空间 backend，不能把尚未归位的子桶当成切片。
- R 只统计保证能在当前固定工作区内彻底完成的子桶。接受节点收费 m；这些 R 记录之后不再进入 block 递归。
- 测试累计 `sum(m_accepted) <= K*n`。这个界只约束接受路径的归位收费，不把普通回退的所有工作也宣称为线性。
- 本轮固定全局 K=4，不按类型或分布选择参数；没有进行 K 搜索。它是候选参数，不据此选择生产默认值。
- 势函数变体单独确定固定、保守的 L 和数值/取整规则，核对势能下降支付条件及望远镜求和。它解决 R=0 时过于保守的问题；不能继承线性 R 版本的同一个界。

### 单层少数桶与延迟物化

- 单层：直方图选最大桶；少数记录、原位置、桶计数/游标及临时记录均计入固定预算。少数桶直接稳定散布到 scratch 的逻辑桶区间。
- 大桶移动按位移符号分段：右移段倒序、左移段正序，原位段不写。用标记身份检查未读记录不被覆盖；实测大桶记录写入次数。
- 延迟：当前大桶用有界空位/区间视图表示。统计所需读取保留，不能把减少搬运写成减少 key 扫描。
- 在抽取下一层任何少数记录前核算新预算，包括 Vec capacity、位置合并暂存、区间视图及少数记录稳定排序的辅助空间。预算不足先整理已有整段。
- 整理范围是进入这段链时的原始数组区间，包含之前缓存的兄弟桶；不是仅整理当前大桶。
- 证明缓存记录始终分居当前大桶的 key 区间两侧。退出时按完整转换 key 稳定排序缓存记录，再整理大桶、填两侧。
- 若当前大桶还有未排序位，整理后从尚未完成的那一位交给普通连续路径。预算拒绝的那一层不能被错误跳过。
- “整段大桶至多整理一次”限定于一段预算允许的链，不宣称所有后续回退/新链的总搬运都是 O(n)。

### 直方图预统计

- 只增加计数表，不增加 sigma² 个输出桶；实际 scatter 仍为 sigma 桶。
- 统计使用固定总预算，按实际计数宽度和容量计费。兄弟表、祖先表及所有尚未释放的容量都占预算。
- 预算不足就扫描该子桶；不能只统计当前正在读取的一行而忽略仍存活的其他行。
- 分开计数“记录重新读取次数”和“计数更新次数”。提前统计不意味着计数运算消失。

## 统一验证与测量流程

1. **固定版本。** 保存源码、编译选项、binary hash、预算参数和控制组版本；每项结果进入独立目录。历史 CSV 不回填为新代码的成绩。
2. **正确性先行。** key＋ordinal＋payload 全身份 oracle；signed/unsigned、转换浮点/NaN、受限值/引用 payload、空数组/ZST、无效参数、变化 extractor 防越界。按改动补充分桶/所有权专属检查。
3. **模型与原生分开。** 小模型只支持其有限状态覆盖；Rust 单测、release、ASan 各自保存日志。不把它们称为完整 unsafe 证明。
4. **先聚焦，再扩展。** 首轮覆盖均匀、共享前缀、95% 重复、长偏斜链；先在 16K/256K/1M 检查目标计数及大回退。通过后才跑四尺度、五布局、七分布的完整矩阵。
5. **同进程轮换。** 输入生成、reset、oracle 在计时外，workspace 分配与排序全流程在计时内。复用输入地址，轮换方法顺序；正常计时与插桩计数分开。
6. **资源串行。** 同一 CPU 上一次只跑一个计时实验；编译、ASan 和其他 benchmark 完成后再计时。聚焦默认 25 个样本，完整矩阵默认 9 个，关键反例单独复测。
7. **同时报时间和空间。** 中位数、样本分散程度、每布局/分布回退、额外 requested heap、明确另计的 stack/allocator/RSS、记录读写、归位次数和峰值存活目录。固定 b 的 O(n/b) 目录不称 O(sqrt(n))。
8. **按证据停止。** oracle/预算/所有权不满足就停止性能阶段；目标工作量没有减少就不归因于该机制；多数场景没有收益或反例明显扩大时保留否定结果，不追加无关内联、展开或按负载分类的补丁。

## 本轮交付边界

用户随后授权并行实现：本轮八项均形成独立候选，再由统一程序串行比较。13 个方法包括 full-scan、free-list、prefix、carry、leaf-batch、joint 0/512KiB、R4、整数势函数、single minority、deferred chain、ordinary 与正确稳定 MSD。各机制不叠加；结果见 [统一报告](strategy_experiment/REPORT.md)。生产 dispatcher、公开库 API 和 LSD 分支保持原有范围。

## 联合候选与参考排序补测

独立实验完成后，再测正交组合：全局 carry＋leaf batch，节点归位 carry＋势函数＋全局组合回退，以及独立打开 digit 单调免搬运的版本。新一轮只保留这三个组合、节点归位基线、Block LSD 的 64/512 两种块长、ordinary MSD、正确 stable MSD、Rust stable sort，共九项；不重跑旧十一项消融。

补测保留原 descending，并新增严格 `n-1..0` 反序，以及 digit 有序但全 key 未排序、最后一对才逆序两个定向输入。九项采用同进程轮换；当前结果与旧二进制数据分目录保存。范围压缩不混入组合。详见 [联合候选报告](combined_experiment/REPORT.md)。
