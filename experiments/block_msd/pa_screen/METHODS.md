# Pa 两条改进线的第一轮筛选

基线为 `1db6268`（其父实验为 `7d91e8c`）。原 Pa 保留；本轮新增候选均在
`frontier/pa.rs`，共用既有 classifier、稳定叶子和分布／compact 后端。
没有按 key 类型调用独立 LSD/MSD 实现，也没有修改主库入口。

| 标识 | 相对 Pa 的变化 |
|---|---|
| Pa_ref | 新节点函数下复现原策略，用于观察实验框架本身的成本 |
| Pa_terminal | 整个剩余 key 已消费时使用 identity 编号，分布后直接完成，不再扫描分组 |
| Pa_ordered | 可提前退出的顺序检查；有序／全等直接结束，其余 variation 扫描不再累计顺序关系；唯一值逆序省略等值组修复扫描 |
| Pa_lean | terminal＋ordered，仅用于验证两项开销修改能否共存 |
| Pa_skew | 原 Pa＋大子桶内的候选准备，有强完整多数证据时用一字节路径编号 |
| Pa_skew3 | 和 skew 相同的信号／准备，但用小于／等于／大于 pivot 的三个有序编号 |
| Pa_both / Pa_both3 | lean＋对应偏斜处理；独立改动有价值后才解释组合成绩 |

Pa 的字节预算仍为每节点 `ceil(log256(m))`，受有效宽度限制。terminal 只正规化
已经等于完整 key 的 classifier，不改变它选择的位数和 radix pass。
ordered 对完整输入验证顺序，不以样本相同作为终结依据。

## 偏斜信号的含义

宏节点结束后的既有等 label 区间扫描，已经知道各子桶的真实大小。若子桶超过父节点
一半，且剩余 cap 大于八位，在子节点必需的准备扫描中融合 Boyer–Moore。
只有最终票数大于该子节点长度的一半，才启用压缩编号。这是候选频数的充分下界，
不是所有真实多数都能通过的检验；没有额外验证全量扫描。

普通节点不准备候选。第一次 Pa 分布仍会发生，其时间、写入和 compact 都计入。
大子桶本身不证明下一步仍然偏斜；多数前缀但完整 key 各异时，候选准备可能纯粹增加成本。
这些情况保留为负例，不把强重复输入的收益推广到所有深偏斜。

三路编号的中间组已完整终结。两侧不一定是一个新二进制前缀，故保守保留当前有效位 cap；
完整多数证据保证每个侧组小于该节点一半。下一节点仍按实际 variation 计算前缀。
它与路径出口编号是共享分布后端下的两个局部 classifier 对照，不继承原 F 的全部 pass 证明。

## 成本与正确性

分布函数独占 scratch，返回后才访问子节点。identity、普通前缀、路径编号与三路编号
使用同一工作区准入预算；内存另用 requested heap peak 验证。堆峰值不含输入／恢复副本、
参考结果、递归栈、allocator 保留量与 RSS，固定 B 的目录仍是 O(n/B)。

计时和工作账本用独立 release ELF，计数由 feature 编译移除；分配统计也单独运行。
新 `order_records` 记录显式顺序探测／等值组修复的访问；原融合扫描按循环记录数计，
提前退出的探测按 key 读取计。它与 prepare / candidate 是用途视图，有重叠，不能直接求和。
`frontier_nodes`／`equal_nodes` 记录实际启用的 classifier，便于区分“支付准备”与“实际使用”。
scatter 不包含比较叶子移动；compact 按完整记录槽位计，包括块 padding 的原始存储复制。

每个方法先 warmup，再轮换并交替反转调用顺序。全部方法恢复同一输入分配；
分配／释放、叶子与终结都在计时内，恢复及完整稳定 oracle 检查在外。
方法表两处放原 Pa，作为 A/A。汇总按相同 seed / rep 配对，保留全部离群值，
不会把最快样本或跨场景均值当作统一胜出的依据。

本轮需覆盖 u8/u16/u32/u64/u128，以及带身份／payload 的布局。先用小矩阵筛选，
只让有收益的改动进入百万条、新种子和 B=512 的确认。B=64 与 B=512 分开解释，
各自保留 heap 数据；不会把 B 的改变写成等预算配对收益。
