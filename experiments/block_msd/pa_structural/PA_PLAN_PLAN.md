# PA value-owned classification plan

Previous source17531ed is rejected and archived at65c540d; caller-capacity code is removed. This candidate keeps B unchanged. The original root library and frozen Block LSD remain unchanged.

`Pa_plan` inherits `Pa_kernel` admission, information mask, ISA context, fanout, recursion and leaf handling. It moves the fixed packed classifier into the record adapter, rather than retaining a nested classifier reference. The packed adapter declares that every processed byte already contains only the supplied prepared-variation bits, allowing distribution to omit a redundant masking adapter. The existing recycled-block scatter, allocation, byte order and compaction protocol are shared. Borrowed classifier support retains old method layouts for same-executable controls. There is no record key sidecar or new allocation. Expected space remains O(B+n/B).

The code-generation hypothesis comes from the rejected capacity executable: a packed Float32Record/u16 specialization loads a classifier pointer and PEXT memory mask per record. Before timing, inspect the current executable to determine whether the new adapter removes that load and allows the mask to stay in a register. A code-generation change is not itself a speed claim.

Correctness: native instrumented library and float full-record tests precede timing. The existing context/geometry test compares all Work fields including exact leaf-length arrays across scalar, context and owned-plan variants. Float tests include NaN payloads, infinities and signed zeros ordered by the repository converted key. Finite comparison-path timings remain separate from special-value correctness.

First timing screen uses one native float ELF on CPU2. It explicitly repeats the earlier f32_id16/sparse16/B512/n1048576/seed42 boundary with sixteen repetitions and four slots [original PA,candidate,candidate,original PA]. A material median>1.05 and p10>1 requires a second independent reversed repeat before rejection; any such repeat confirmation stops larger scopes. If that boundary passes, screen uniform/sparse16 across f32/f64/f32_id16/f64_id32, B512, n1048576, new seed20261025 with sixteen repetitions of eight rotated slots [candidate,original PA,prior kernel,raw Rollercoaster,frozen Block LSD,prior kernel,original PA,candidate]. Any median>1.05, including p10<=1 ambiguity, receives a separate reversed sixteen-repetition four-slot confirmation at seed42. Do not tune admission to a failing cell.

After a passing initial screen, continue B64 counterparts and scalar normal/subnormal shapes, then representative integers and ordinary-ISA counterparts. Fresh builds and source hashes are required; no timings overlap compilers, tests or other benchmarks. Full acceptance still requires the original103 integer cells, finite/special float matrices, ordinary-ISA screens, holdouts, frozen-original ABBA, measured allocations and separate Work. Earlier results do not transfer; other machines remain unverified.
