# Conservative PA hardware packing: final independent cohort

Count-derived completion and its combination are rejected at67925bf. Their module, bucket-length API, policy flag, dispatch methods and tests are removed. This cohort keeps only `Pa_strict`: the6fceaaa checked hardware execution context, with selection requiring at least two saved physical record passes. The rule is a conservative empirical guard after a one-pass saving failed; it is not a throughput theorem. Original PA and the prior kernel remain same-program controls. Root library and frozen Block LSD are unchanged; the experimental block kernel is byte-identical to6fceaaa.

No new completion scheduler, cached key, block capacity change, key sidecar or allocation lifecycle is introduced. Native, hardware-disabled and float correctness must precede timing. Validate stable identities/payloads, special IEEE bit patterns, B3/64/512, and cross-compile AArch64/RISC-V. Cross compilation is not a real-machine performance result.

Fresh frozen executables and current-source evidence are required. Eight screen slots are [strict,originalPA,priorKernel,Rollercoaster,frozenLSD,priorKernel,originalPA,strict], with16 rotated/reversed repetitions. First run the previously failing f32_id16/sparse16/B512/n1048576/seed42 boundary; then8 native float uniform/sparse16 cells,26 native integer representative cells,8 generic float cells and26 generic integer cells, with screen seed20261027. All comparisons to originalPA are audited. Any median>1.05, including ambiguous p10<=1, receives an independent16-repetition four-slot reversed confirmation at seed42 (use seed7 if the flagged cell is already seed42). Confirmed median>1.05 and p10>1 rejects this candidate. No threshold tuning or type-specific routing follows a failed cell.

After those gates pass, run the existing current-source full matrices: original103 native integer cells;88 native finite float cells plus16 special cells;46 generic integer cells plus the existing7 large-record/skew additions;32 generic finite float cells plus16 special cells;30 fresh integer holdouts and16 float holdouts on both targets;17-cell frozen-original ELF ABBA. Preserve same-program A/A, single-ELF cohorts, exact input sets and full-record oracles. Verify ambiguous>5% medians independently before retention. Other-machine performance remains unverified.

Separate Work runs check actual retained/rejected packing geometry; instrumented wall time is excluded. Separate memory runs cover native integers and all four float layouts at B64/B512, uniform/sparse shapes, n1048576, against originalPA. Measure peak heap, allocation counts and workspace release. Final evidence must record hashes, flags, CPU affinity, process faults, host-wide swap counters and interrupted groups. No benchmark overlaps compilers, tests or another benchmark.

Retention requires broader measured majority wins over raw Rollercoaster in the original integer matrix, no confirmed material regression versus originalPA in the declared cells, stable full-record correctness and the existing workspace bounds. Float weaknesses remain explicit; the user's supplementary float request does not imply a claim of majority wins in every float layout.
