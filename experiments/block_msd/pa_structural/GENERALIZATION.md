# 既有机制的泛化审计

判据：找出原机制所消除的真实工作、当前限制及其正确性来源；泛化必须保留稳定顺序和空间生命周期，并单独测量。下列候选不是已证实优化。

| 既有机制 | 当前限制 | 可以泛化的对象 | 可验证收益与代价 |
|---|---|---|---|
| 精确相等多数 / PrefixBand | 单个 key 或一个共享前缀区间，要求 >n/2 | 小型有序 key 集合，共同覆盖 >n/2；精确命中终止，键间区间递归 | 吃到“少量任意宽键、各位高度相关”的输入，变化位投影不能把相关性变成少位。代价是采样、精确覆盖证明和每次分类的多比较。 |
| 单 bit grouped scatter | 一字节恰有一个变化位，且记录不大于机器字 | 2/3 个变化位的小字母表，或由投影得到的紧凑小字母表 | 多个桶分别用有序位图写入，减少重复更新桶指针。位图构造/桶数开销和原有回收证明必须重新验证；不能直接套二路代码。 |
| 最高字节的局部完成 | 只尝试一个最高字节切分，精确 histogram 只作 admission | 多级最高有效 digit 的受预算细分；将已证实 populations 一并交给后续边界遍历 | 适应不同规模/记录宽度；代价是额外计数和更多节点。保留整个标签的稳定总序；中间字节不能直接当 MSD 边界。强制本地调度首屏已经失败，因此优先复用已得计数，再考虑调度扩张。 |
| prepared variation 复用 | 复用全节点变化掩码，子 run 仍扫描边界/重新准备 | 分发产出的精确桶长度、每桶 OR/AND、顺序事实作为子节点准备信息 | 可省扫描，但需核算每记录多次 reduction、桶状态和存活期。已试“只携带下一段首标签”没有稳定收益，说明单纯减少计数不够。 |
| 全等 XOR/OR 与有序归约 | 等值关系可向量化；软件宽键靠早退 | 精确的顺序/相等证明共用已加载 key，按比较能力形成小块证书 | 改进单调输入的实际扫描成本；不会由投影自动得到收益。必须保留反例早退，以及全等/重复/唯一反序分别验证。 |
| 固定规模的字节前缀预算 | 预算由节点 n 决定，不用实际 populations | 用受预算直方图证实的分布决定一次消费多少有序信息 | 可能减少递归和小叶子，但额外扫描与表成本可能抵消；不可用样本直接当正确性事实。 |

优先独立筛选小型有序 key 集合：它把旧相等多数机制推广到“集合多数”，能覆盖位投影无法表达的相关性，而不是在已获益的稀疏位场景继续加分支。以精确 >n/2 覆盖保证所有未命中子区间总量 <n/2，沿用原始坐标 cap；因此不会引入不收缩的递归。所有命中 key 单独终止，间隙标签保持总序。仅固定容量的节点状态，不缓存逐记录标签。只有实测通过后才保留。

筛选设计：基线为旧 PA 与已归档的 `Pa_packed`，另设单独集合分类与组合两个消融。除既有 `few`（8 个任意间隔键）外，补充固定随机字典的4/8键、10%任意键噪声，以及变化位投影信息量对照。测试完整 key/ID/payload，包含样本命中而完整覆盖不足一半的拒绝边界。策略只在原有 root/heavy 机会、宽度超出普通前缀预算、无已批准 PrefixBand 时付出采样/证明成本；已有完整一字节投影优先。普通路径没有新增逐记录状态。

集合采样 gate 在首轮计时前固定：样本全体至多8个不同 key 时全部保留；否则仅保留出现至少3次的 key，总支持需至少48/64。相较在原准备扫描中融合计数的 PrefixBand，这里会另付一次精确覆盖扫描，故成本 gate 更保守；正确性仍由完整数据的严格多数证明负责。补充50%和90%任意键噪声的拒绝/回退对照。
