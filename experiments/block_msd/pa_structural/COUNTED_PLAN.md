# Independent PA counted completion and conservative packing

The value-owned plan is rejected at a34545b / bc375d8: a real register-mask PEXT difference does not give consistent total-sort benefit. All value-owned adapter and normalization changes are removed. Caller-capacity and cached-leaf mechanisms remain removed. This cohort starts from the original6fceaaa PA implementation and retains it as a same-program control.

The failed sparse16/f32 record case changes active digit counts from64/32/32 across three original passes to256/256 across two packed passes. This is reproduced from actual xorshift inputs at seed42 and20261025, preserved in pa-packed-f32-fanout.json. It establishes a fanout change; without hardware counters it does not prove cache attribution.

Three independent methods share one executable:

- Pa_strict retains hardware packing and its ISA context, but requires at least two saved physical record passes. Complete projected labels compare against all active original-key bytes; partial labels compare against the old prefix bytes. This is a conservative empirical guard after one-pass savings failed, not a throughput theorem. It may discard useful one-pass savings. No type/layout-specific routing or parameter sweep is used.
- Pa_counted_key starts from original UnifiedGroups, without packing. Only an ordinary nonterminal prefix can finish the entire remaining key, and only when that needs at most one extra active byte beyond the old prefix. Wide random keys retain the original comparison-leaf route. Oversized arrays perform one stable MSD pass with the existing recycled-block sorter. Exact bucket lengths are derived from existing final partial-block metadata after this same pass, with no new histogram scan. Children fitting the unchanged512*B*sizeof(T) record-plus-histogram budget finish with the existing dense Block LSD; oversized children repeat the MSD operation. Every parent workspace drops before child recursion.
- Pa_strict_counted combines exactly those mechanisms. Each component is audited separately; a combination gain cannot substitute for component evidence.

No scatter/fixup/compact algorithm changes. The new step_with_lengths interface adds a read of already-completed directory metadata. Root library and frozen Block LSD are unchanged. Count arrays add2KiB per live converted-key byte, at most32KiB for128-bit keys; these stack constants are separate from heap budget. There is no O(n) key sidecar. Measure final allocation peaks, do not infer them from Work.

Correctness precedes timing: full native instrumented library and float harness, full identities/payloads/stable ties, IEEE special bit patterns, B3/64/512 and integer bit embeddings. A new test proves exact bucket lengths and stable digit order across empty buckets, constant bytes and partial tails; returning lengths must invoke classification exactly n times, with no second pass. Direct completion tests cover conservative masks and scratch boundaries. A new selection test verifies the stricter saved-pass boundary.

First gate: explicit f32_id16/sparse16/B512/n1048576/seed42 with sixteen repetitions of twelve slots [combined,originalPA,strict,counted,priorKernel,rawRollercoaster,frozenLSD,priorKernel,counted,strict,originalPA,combined], CPU2. Audit all three candidates. If no confirmed original-PA regression, the initial eight-cell screen uses uniform/sparse16 across four float layouts, same n/B, fresh seed20261026 and the same sixteen-repetition rotation. Candidate/BASE median>1.05, including ambiguous p10<=1, receives a reversed independent sixteen-repetition four-slot confirmation at seed42. Confirmed median>1.05 and p10>1 rejects that component and its combination; do not tune thresholds to rescue a failed cell. If rejected components are removed before the full matrix, the changed final source needs fresh executables and screens.

After passing native initial cells: B64 equivalents, normal/subnormal shapes, representative integer widths/payloads plus q64 and deep_unique90, then ordinary-ISA equivalents. Full acceptance remains current-source original103 integer cells, finite/special float matrices, native/generic holds, frozen-original executable ABBA, separate allocation and Work. All hashes and build settings are frozen; no timing overlaps compilers, tests or other benchmarks. Other-machine results are unverified.
