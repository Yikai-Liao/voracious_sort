# Block LSD 当前公开接口

```rust
block_lsd_stable_radixsort(&mut values, 8);
```

只公开这个两参数入口。radix 仍显式指定，范围 1–8；块长自动选择。手动块长版本是模块私有函数，单元测试直接验证它，外部用户不能调用。

对 n 个 s 字节的元素、R=2^radix 个桶，块长为 `max(1, ceil(4*sqrt(9*n/(2*R*s))), floor(1024/s))`。radix=8 时与现有 c=4 / 1 KiB 下限实测策略一致。该系数在 radix=8 上选定，其他 radix 保留通用空间平衡公式，没有宣称同等性能调优证据。

封装先检查 radix，再处理空/单元素/零大小类型，避免除零；计算公式前转换为浮点，避免 usize 中间乘法溢出。排序核原样保留，源文件函数体已逐字比较。辅助空间对固定 radix 和元素大小为 O(sqrt(n))。

原手动参数测试迁入私有模块；公开 API 用集成测试覆盖。默认 Dispatcher 未更改。

既有图测量的是排序核及相同实参，不包含新增封装计算块长的时间。本次未重新运行性能矩阵。
