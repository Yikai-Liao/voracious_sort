# 图表验收

本任务使用 Python/matplotlib 绘制、预览和导出全部定量图。PDF/SVG 为可编辑矢量成品，PNG 为 300 dpi 预览；本包用于 PR 评估，不是期刊投稿文件。图和结论对应本机测量，未作显著性检验。

## 自动检查

- `source-audit.json`：源码语法、字体、对数轴、导出和对齐门禁检查。19 PASS、2 WARN、0 FAIL。
- `*.alignment.json`：在最终画布上测量 plot area；多面板边界、尺寸、标签锚点和重复间距的容差为 1.5 pt。主图、参数图、增长图通过；矩阵每页只有一个数据面板，对齐不适用，色条明确排除。
- `*.glyph-audit.json`：最终 PDF 的实际字形大小检查，要求全部 ≥5 pt；不存在被 mathtext 缩小的上下标。
- `*.collision-audit.json`：对最终四份 PDF、共十二页检查文字、路径和页面边界，FAIL=0、WARN=0。标记 PDF 仅用于诊断。
- `render-provenance.json`：本次绘图源码、两份汇总 CSV 的 SHA-256 和绘图运行环境。
- 所有页宽 183 mm；主图、参数图和增长图高 180 mm，矩阵每页高 160 mm。实际使用 DejaVu Sans，字体文件及哈希见 `../environment-final.json`；图中无中文字形。

两条源码 WARN 已逐项接受：`EXPORT-RASTER` 提醒没有 TIFF；`RASTER-DPI` 提醒 300 dpi 未达到默认的 600 dpi。这两条针对投稿位图。本任务交付 PDF/SVG 矢量图和 PNG 屏幕预览，不以 PNG 代替矢量成品，因而不增补 TIFF。

## 读数与视觉检查约定

T：六次时间观测（三种子 × 正反方法顺序）的中位数，范围为完整最小值–最大值。M：三次独立内存观测的中位数及完整范围，指标为排序额外存活请求堆峰值，排除输入和分配器内部元数据。确定性输入在不同种子下可能相同，不能当作六个独立随机数据集。

矩阵格子为六次配对耗时比的中位数，分母是同批 TimSort。为保持密集矩阵可读，不逐格画区间；完整区间在 CSV 中。颜色在 1/8、8 截断，原值不截断；灰色 N/A 是接口不支持，叉号是完整输出与稳定 oracle 不同。深色格用白叉，浅色格用黑叉。标注 [U] 的接口本来不承诺稳定性，不将这些叉号都解释成违反接口契约。

逐面板检查了标题、刻度、数据与误差范围、图例、页边、同参数重合和差异标记，并检查组装后的整页。早期斜排标签的边界框重叠已改为竖排，最终版重新审计；未改变数据或放宽检查阈值。曲线用颜色、线型及点形共同区分；参数图的点形表示块字节数低于/等于/高于 4 KiB。相同参数造成的重合在脚注中明确，不作独立算法证据。
