# PA radix improvements

The current source contains two radix mechanisms and retains PA’s original <=128-record comparison leaf. It adds no comparison-sort fallback or natural-run merge completion. Earlier hybrid experiments remain in frozen revision-1–12 packages, outside the current source and the PA-core acceptance claim.

1. **Translated interval.** A bounded native-width sample admits an exact min/max/variation proof for a narrow interval crossing a binary carry. Subtract the proved minimum and use the existing radix distributor only when completing the translated full key takes no more byte passes than PA’s original first prefix. An unsampled outlier rejects admission. This is numeric interval width, not arbitrary sparse-bit packing. Root admission is restricted to inputs exceeding PA’s existing 512*block-record workspace.
2. **Constant-tail completion.** The exact preparation mask already identifies every varying native key bit. If the chosen prefix omits only constant low bits, sorting its labels finishes the full keys. Mark that partition terminal and omit child order proofs, frontier scans and leaf calls. No extra input scan, record buffer, scatter pass or runtime policy flag is introduced. The proved-complete label has a separate classifier type so ordinary prefix partitioning retains its constant nonterminal parameter. A low-bit outlier prevents this completion.

The existing tiled stable order proof and fixed UnifiedGroups fallback are reused. The recursive PA entry and signatures are unchanged. A rejected exact interval proof returns through the ordinary entry, allowing its existing order check to run again rather than changing recursive state or policy. The c4 + minimum 1 KiB block policy is unchanged. The production Block LSD PR is untouched.

Revision 13 is the first combined pure radix candidate. Revision 14 restores the original recursion and isolates the core change to the constant-tail terminal condition. Its new correctness test checks stable identities/payloads, nonzero constant low bits, and a low-bit outlier; work counters verify that the exact positive case completes without child visits. Target and broad screens precede a single complete candidate-only matrix. Older algorithm timings are reused throughout.

The comparison-completion experiment was rejected in a 36-cell paired screen: 17 of 18 near-sorted cells lost over 10 percent. Natural-run merging showed large gains but is a hybrid strategy, so its timings are not reported as improvements to PA’s radix core. Older reports and all failed observations are preserved.

Revision-13 target screening: 26 cells, no median loss over 10 percent. Interval-target ratios are 0.254–0.739; low-constant-bit ratios are 0.546–0.615. The 42-cell broad screen retains seven median losses over 10 percent, mostly n=1024; none has every observation over 10 percent or above both A/A envelopes. These losses remain visible and prevent a no-regression claim. Revision 14 failed the broad gate (12 median losses above 10 percent). Revision 15 retains the original unmeasured PA/strict dispatch arms to reduce a compiler-context confound; only the new pa_radix method is scheduled. Its 14-cell diagnostic still has five median losses above 10 percent. Revision 16 isolates the complete-prefix distributor specialization, but its 14-cell diagnostic still fails: seven median losses above 10 percent. Current status: NOT ACCEPTED. No full matrix has been launched; REPORT.md contains target gains and unresolved losses.
