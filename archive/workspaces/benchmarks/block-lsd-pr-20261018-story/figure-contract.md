# 图的论证与阅读顺序

读者先看选定候选与其他算法的逐条件比较，再看为何选择 block 策略，最后看拟合是否值得采用。主张限于已测输入和有限策略族，所有退化保留；不预设唯一最快、所有条件内存更少。

最终候选复用相同有效参数的既有实测调用，补测仅 32 条时间和 210 条内存；完整重跑已取消。耗时配对不跨批次。原始、扩展、前缀和缺口来源逐行公开，不按最快批次筛选。内部参数选择只使用已完成 109 条件扫描。n<=128 为共同稳定比较叶子，不用于指数识别。

图 1 的类型分面和效率总览的测试集 CDF 回答不同问题。前者定位例外，后者总结工况覆盖；都不能表示重复计时方差。原先跨类型 GM+min/max 误差条式图和随后无数字热力图不作为最终交付。图法依据见 VISUALIZATION-RESEARCH.md 的一手论文与具体图号。

退化解释使用原批次 stable LSD/core 对照和代码；c4 的跨接口绝对时间不拼入旧 core 对照。cache 冲突仍为待测假说。改进候选单列，尚未实现或计时。
